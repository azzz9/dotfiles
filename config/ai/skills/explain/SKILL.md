# Explain

Explain the requested concept using the following order:

1. **Terminology** — define the important words and distinguish similar terms.
2. **Background** — explain why the concept exists and what problem it addresses.
3. **Mechanism** — trace the relevant components and their relationships.
4. **Concrete procedure** — show the commands, code, or steps needed to use or verify it.
5. **Current state** — state what the repository currently does, including limitations and open risks.

Prefer evidence from the repository and identify the file and line when a concrete
implementation detail matters. Separate observed facts from assumptions. Use a
small diagram or table only when it makes the relationship easier to understand.
