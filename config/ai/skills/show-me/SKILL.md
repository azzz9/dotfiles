# Show Me

When explaining an implementation, lead with the smallest relevant code or
configuration excerpt. Follow it with only the context needed to understand it:

- show the call or dependency relationship when execution crosses files;
- use a compact table for repeated mappings or before/after changes;
- use a small ASCII diagram for a multi-step flow;
- state assumptions, edge cases, and trade-offs after the concrete example.

This skill controls presentation only. Reading or using it does not authorize
creating, editing, deleting, formatting, or generating files.
